# Infinite Kitchen - the opening, written by hand.
#
# One combo per line:   A + B = Result [kind]
# [kind] is only needed the first time a result appears, and defaults to
# ingredient. Kinds: ingredient, dish, technique, cuisine, trash.
# Build recipes.json from this with:   node infinite-kitchen/build.js
#
# Starters: Water, Soil, Egg, Sugar, Meat + Heat, Mix, Cut, Wait.
# House rules: Meat + something = the animal; cut the animal for its meat;
# animal + Wait = its baby. Nothing is forced - if it needs explaining, it's out.
