# Infinite Kitchen - more variants: things that are a form of something
# more basic. "except techniques" means cooking it works its own way (the
# rules, or its own lines), not like the raw thing.

## Cured and cooked meats go with food the way their meat does
Ham acts like Pork except techniques
Honey Ham acts like Pork prefix Ham except techniques
Bacon acts like Pork except techniques
Sausage acts like Pork except techniques
Salami acts like Pork except techniques
Corned Beef acts like Beef prefix Corned Beef except techniques
Jerky acts like Beef prefix - except techniques
Wagyu acts like Beef
Minced Meat acts like Beef prefix - except techniques, Egg, Dough
Meatball acts like Minced Meat prefix - except techniques
Patty acts like Minced Meat prefix - except techniques
Smoked Salmon acts like Fillet prefix Salmon except techniques
Surimi acts like Crab prefix - except techniques
Turkey Breast acts like Chicken renaming Chicken to Turkey prefix Turkey except techniques
Duck Breast acts like Chicken renaming Chicken to Duck prefix Duck except techniques
Drumstick acts like Chicken prefix Chicken except techniques
Rabbit acts like Chicken renaming Chicken to Rabbit except Cut, Wait, Heat, Simmer
Caviar acts like Roe prefix -
