# Infinite Kitchen - the hand-written core (restart, 2026-10-04).
#
# One combo per line:   A + B = Result [kind]
# Pairs are unordered. [kind] only on a result's first appearance; it
# defaults to ingredient. Tools are the ones in the room: Stove, Oven, Pot,
# Knife, Blender, Clock, Fridge - seven, all usable from the start. Players
# discover food, never tools. The Stove does all pan cooking (fry, grill,
# sear); the Clock is time in every form (age, ferment, grow, spoil).
#
# Elements: Water, Grain, Plant, Animal, Salt, Sugar.
#
# When it isn't obvious what a pair makes, think of everything food can be,
# not just cooking: groceries, snacks, candy, brands, restaurants and their
# iconic menu items, baking, drinks. Animal + Candy is nothing in a recipe,
# but it's Gummy Bears in the candy aisle. Use that range to find the answer
# that clicks; don't go looking for ways to squeeze brands in.
