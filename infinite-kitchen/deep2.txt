# Infinite Kitchen - variants. "X acts like Y except A, B" gives X every
# recipe Y has, except the pairs listed (and any pair written for X by hand,
# which always wins). Only for things that really are a kind of Y.

## Whole eggs are eggs
Quail Egg acts like Egg prefix -
Duck Egg acts like Egg prefix -
Free-Range Egg acts like Egg prefix -
Salted Egg acts like Egg prefix - except Wait, Hen, Chick
Ostrich Egg acts like Egg prefix -
Quail Egg + Wait = Quail
Duck Egg + Wait = Duckling
Duck Egg + Meat = Duck
Salted Egg + Wait = Salted Egg
