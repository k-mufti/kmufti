# Infinite Kitchen - the catalog: every food we want in the game.
#
# Not combos - a checklist. Each section is a real aisle, menu, cookbook or
# occasion, so coverage comes from how the world already sorts food, not
# from memory. For anything missing, the question is "how is this actually
# made?" - its combo comes from its real recipe. If there's no honest route
# yet, it waits; a gap is better than a forced combo.
#
# Names are written the way the game names things (what you'd say out loud).
# An item may sit in more than one section. node core.js reports how much of
# each section is in the game (--list shows what's missing).
